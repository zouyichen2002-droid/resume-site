展开记忆连续性、后端诊断与评测边界+

上下文衔接 · 技术机制

短回答需要保留前置问题

“蓝色”依赖“你喜欢什么颜色？”解释。SourceContext 保留问句，证据限定为用户原文；长期记忆应用前保护问答，让保护标记穿过历史窗口和二次装配，进入原生 History。

恢复检查点

派发、应用、向量就绪分别检查

推理先落版本化快照，再 Apply 业务记忆，完成后写 applied_at。快照复用推理结果，幂等约束重复应用；向量是后续投影，不能把已派发当作可召回。

模型故障

是否已输出，决定能否切备用

主模型尚未输出且预算允许时切备用；交付增量后失败不自动从头重播。请求幂等与数据库租约约束执行资格和结果提交，模型调用放在回复事务之外。

后台诊断

API 可用，后台也可能停滞

历史记录包含 495 条 Outbox 积压和 3 个 Worker 未启动。排查沿队列认领、Temporal Activity、applied_at 和投影展开，以状态和消费进度检查后台链路。
